--A visual particle game made with pygame--

--CONTROLS--

P - Pause

R - Reverse -> makes particles run away from the mouse

E - Enable Physics -> particles get pulled by gravitation towards the mouse

T - TP -> particles get teleported to your mouse

M - Changes color mode -> on default it alternates between different colors, on second mode their color changes according to their velocity

W - weird -> particles form a circle around the mouse

A - Toggle Attract -> on default particles gravitate to mouse, when pressed they stop gravitating
